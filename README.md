# The Sound of Ethiopia

A multi-page HTML site exploring six traditional Ethiopian musical instruments: Krar, Begena, Masinko, Embilta, Washint, and Kebero.

Built with plain HTML (no CSS or JavaScript) for Web Programming I.

## What's Inside

- `index.html`: Home page introducing Ethiopian musical heritage, instrument links, cultural context, and project overview
- `pages/instruments.html`: Comparison table, playing methods, credited photos, and cultural notes
- `pages/contact.html`: Contact form with input validation and direct contact details
- `images/`: Instrument illustration and photos

## Viewing the Site

Open `index.html` in a browser, or run it through Live Server in VS Code.
